These notes are for those who wish to re-build or re-compile the plug-ins with MinGW, but don't want to (or can't) use the Code::Blocks IDE software.

In this file you will find the compiler and linker options and commands used to build the plug-ins as they are.
This text file also briefly touches on what pre-processor DEFINEs can be passed to the compiler to make the source code build in special ways.

Regarding "custdata_types.h": ("Custom Data Types Source Header")

Nearly all of the plug-ins use this header.  It checks for preprocessor DEFINE options when compiling, to decide how to build the plug-ins, and then what data types
to assign via TYPEDEFs to various data type names.

The names that are used for declaring variables elsewhere in the code are as follows:

fhx == long double (always) (set to full 128-bits with compiler options)
fsx == double (always)
flx == float (always)

f9x == float OR double OR long double (depends on preprocessor DEFINEs when compiling)*

u9x == unsigned long long
s9x == signed long long
u7x == unsigned short
s7x == signed short

*The available options when compiling are to define ONE of the following:

PRECISION_LOW		// Makes (f9x) equal to (float)
PRECISION_NORMAL	// Makes (f9x) equal to (double)
PRECISION_HIGH		// Makes (f9x) equal to (long double)

If none of the PRECISION values are given, the code will *assume* PRECISION_NORMAL and make (f9x) equal to a (double).

Plug-in compiler options that I use:

-static-libgcc

-trigraphs		// Needed for the VSTGUI SDK to build properly without errors
-m128bit-long-double
-msse4.2		// Used only for SSE 4.2 builds
-m64			// Used only when building 64-bit DLLs
-ffinite-math-only
-fno-signed-zeros
-fno-trapping-math
-mfpmath=sse		// Only when building with SSE
-malign-double

-----------------------
